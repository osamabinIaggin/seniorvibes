01 — the trigger is yours

It's a sentinel, not a logo.

A directive is any line where your trigger token comes before an instruction. The default is $#, but it's one setting — pick whatever stays out of your way. It can sit on its own line or trail real code.

$# // default //ai >> #! @do

02 — what makes it different

Grounded, clean, and left for you to review.

Grounded, not guessed

The symbols you name are resolved through the language server, so the code uses their real signatures — not a plausible hallucination.

Clean output

No marker comments. New code is highlighted then fades to normal, and the directive auto-removes — leaving only code.

Compound directives

Stack several on adjacent lines and they generate together, in order, as one coherent block.

Never corrupts the buffer

Atomic edits, a staleness guard, and exact-text tracking. Re-runs replace; mistakes never clobber your code.
